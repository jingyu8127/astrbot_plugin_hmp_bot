# astrbot_plugin_hmp_bot


> **插件标识（name）：** `astrbot_plugin_hmp_bot`
> **显示名称（display_name）：** HMP Bot
> **适用平台：** AstrBot 插件（Python）

---

## 插件介绍

HMP Bot 是一个面向 [HaulMP](https://haulmp.com)（卡车模拟联机）玩家的 AstrBot 插件，让你在聊天里直接查询玩家资料、检索用户、查看服务器状态，并获取实时定位与全量路况。

**功能概览**
- **账号绑定**：将聊天账号与 HaulMP 论坛账号绑定（最多 3 个，首个为主账号），绑定后多数指令可省略用户名。
- **资料查询**：分组展示玩家全部字段（基本信息 / 车队 / 驾驶指标 / 论坛指标），支持纯文本或头像图文卡片两种输出。
- **用户检索**：按用户名 / 显示名模糊搜索，支持数值、布尔、文本三类字段筛选。
- **服务器状态**：查询在线人数与客户端版本。
- **实时定位**：查询指定玩家实时坐标与附近玩家，输出地图（图片）或文字摘要。
- **全量路况**：汇总当前在线玩家分布与行驶 / 停靠统计，输出地图（图片）或文字摘要。

**适用场景**
- 车队 / 社群在群里快速核对成员资料与在线情况。
- 跑长途时查看好友实时位置与周边车流。
- 无需离开聊天软件即可掌握服务器负载与版本。

**配置项**
| 配置项 | 说明 |
|--------|------|
| `output` | 资料查询输出格式：`text`（纯文本，默认）或 `image`（头像 + 图文卡片） |

> 所有指令均兼容带 `/` 或不带 `/` 的写法（如 `/查询 用户名` 与 `查询 用户名` 等价）。

## 指令说明

| 指令 | 参数 | 功能描述 | 示例 |
|------|------|----------|------|
| `绑定` | `[用户名]` | 绑定 HaulMP 论坛账号（每人最多 3 个，首个为主账号）。绑定后其他指令可省略用户名。 | `绑定 用户名` |
| `我的绑定` | 无 | 查看当前账号已绑定的所有 HaulMP 账号。 | `我的绑定` |
| `解绑` | `[序号 \| 用户名 \| 全部]` | 解绑账号：可按绑定列表序号、用户名，或 `全部` 一键解绑。 | `解绑 1` / `解绑 用户名` / `解绑 全部` |
| `查询` | `[用户名]` | 查询玩家资料，分组展示全部字段。已绑定且省略用户名时查询主账号。 | `查询 用户名` |
| `搜人` | `[关键字] [筛选条件 ...]` | 按用户名 / 显示名模糊检索，可叠加字段筛选（数值 / 布尔 / 文本）。 | `搜人 jing 里程>10000` |
| `服务器` | 无 | 查询服务器状态：在线人数、客户端版本。 | `服务器` |
| `定位` | `[用户名]` | 查询玩家实时位置，标注附近玩家，输出地图图片或文字摘要。已绑定且省略用户名时定位主账号。 | `定位 用户名` |
| `路况` | 无 | 全量在线玩家路况，含地图热力与行驶 / 停靠统计，输出图片或文字摘要。 | `路况` |
| `菜单` | 无 | 显示指令菜单。 | `菜单` |

### 搜人筛选条件
`搜人 [关键字] [筛选条件 ...]`，按**用户名 / 显示名**模糊检索（不分大小写），筛选条件可叠加：

| 类型 | 写法 | 示例 |
|------|------|------|
| 数值 | `字段>值` / `字段>=值` / `字段<值` / `字段<=值` | `里程>10000`、`交付>=10`、`支持者>=2` |
| 布尔 | `字段`（=是）或 `字段=是/否` | `管理员`、`车队成员=是`、`在线=否` |
| 文本 | `字段=值`（子串匹配） | `角色=管理员`、`国家=德国` |

支持的筛选字段：用户名、显示名、用户ID、角色、管理员、支持者、在线、车队成员、里程、交付、最长单程、活跃天数、帖子、声望、国家、签名、注册时间、最后活跃。

> ⚠️ 车队名称 / 车队标签 / 简介 / 个人网站 / 驾驶时长仅在「查询」详情中展示，无法用于「搜人」筛选。

### 定位 / 路况输出说明
- 正常情况输出 **地图图片**（基于真实 ETS2 路网底图 + 标记 / 热力）。
- 插件加载时会**自动安装**渲染所需的 Node 环境：若系统 PATH 无 `node`，自动下载便携版 Node 到插件目录 `nodejs/` 并执行 `npm install` 拉取 Puppeteer / Chromium，无需手动配置（首次加载可能较慢，取决于网络）。
- 当自动安装失败（网络受限等）或底图瓦片加载失败时，自动改为 **文字摘要** 输出，不影响信息查询。

### 查询在线状态说明
「查询」资料卡中的**在线状态**反映**游戏内**是否在线（取自实时地图在线玩家列表）；若实时地图暂不可用，则降级显示论坛平台在线状态并标注「（游戏内未知）」。

> **已知限制（汇总）**
> - 定位 / 路况图片渲染依赖 Leaflet + Puppeteer；插件加载时会自动安装 Node 与 Chromium，若网络受限导致安装失败则降级为文字输出。
> - 实时数据依赖 HaulMP 官方接口（`forum.haulmp.com` / `haulmp.com` / `map.haulmp.com`），接口变动或不可用时相关功能会降级。
> - 资料查询 `image` 模式依赖头像 URL 可访问。
> - 绑定数据以本地 JSON 文件存储于插件数据目录。
