# astrbot_plugin_hmp_bot

HaulMP（永魂卡车模拟联机）平台 AstrBot 插件：绑定论坛账号，查询玩家资料与服务器状态，并支持**实时定位**与**全量路况**（基于 `https://map.haulmp.com/api/live` 实时接口）。

## 功能与命令

所有命令兼容带 `/` 或不带 `/` 的写法。

- 绑定账号：`绑定 [用户名]`（每人最多 3 个，首个为主账号）
- 我的绑定：`我的绑定`
- 解绑：`解绑 [序号 / 用户名 / 全部]`
- 查询资料：
  - 未绑定：`查询 [用户名]`（必须带用户名）
  - 已绑定：`查询`（省略用户名，直接查主账号）
  - 资料卡含：用户名 / 显示名 / 用户ID / 注册时间 / 最后活跃 / 在线状态 / 角色 / 是否管理员 / 支持者等级 / 个人网站 / 签名 / 简介 / 活跃天数 / 车队成员 / 车队名称 / 车队标签 / 论坛与驾驶指标（总里程、驾驶时长、交付、最长单程、帖子、声望等）
- 检索用户：`搜人 [关键字] [筛选条件 ...]`
  - 按**用户名/显示名**模糊检索（如 `搜人 jing`）
  - 筛选条件：数值 `里程>50000`、`交付>=10`；布尔 `管理员`、`车队成员=是`；文本 `角色=管理员`、`国家=德国`
  - 可多条件叠加，例如 `搜人 west 管理员 里程>10000`
- 服务器状态：`服务器`（在线人数 / 客户端版本）
- 实时定位：`定位 [用户名]`
  - 已绑定可省略用户名：`定位` 直接定位主账号
  - 返回**地图图片**：被查用户的真实经纬坐标用红色标注，并标出附近 60km 内的其他玩家；图含经纬网格、比例尺、指北针
- 实时路况：`路况`（返回**地图图片**：全量在线玩家散布点 + 行驶/停靠/安全区统计 + 服务器在线状态）

> 定位与路况基于 `https://map.haulmp.com/api/live` 实时接口；游戏坐标经球面 LCC 投影在本地复刻换算为真实经纬度后，用 Pillow 在本地渲染成地图图片（无需外部瓦片，任何环境均可出图）。

## 依赖

- `Pillow>=10.0.0`（地图图片渲染，已在 `requirements.txt` 声明）

## 输出格式

配置项 `output`（在插件 WebUI 中设置）：
- `text`：纯文本（默认）
- `image`：头像 + 文本图文卡片（仅作用于「查询」资料卡）

## 目录结构

```
astrbot_plugin_hmp_bot/
  metadata.yaml      # 插件元数据（必需）
  main.py            # 插件代码主体（必需）
  _conf_schema.json  # 插件配置 Schema（可选，提供 WebUI 可视化配置）
  requirements.txt   # pip 依赖（可选）
  README.md
```

## 开发原则

- 持久化数据存放到 `data` 目录，避免更新被覆盖。
- 网络请求使用 `aiohttp`，禁止使用 `requests`。
- 日志使用 `from astrbot.api import logger`。
- 提交前使用 `ruff` 格式化代码。

## 调试

启动 AstrBot 本体后，将本插件放入 `AstrBot/data/plugins/` 目录，
在 WebUI「插件」页面对应卡片点击刷新图标即可热重载。
